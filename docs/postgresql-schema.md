# PostgreSQL 스키마

이 스키마는 3D 생성 작업, 생성된 GLB 자산, 월드 배치, Meshy 애니메이션 카탈로그와
참조 이미지 생성에 필요한 설정 및 모델 카탈로그만 저장합니다. JWT의 사용자는 외부
인증 시스템이 소유하므로 이 서비스에는 사용자 테이블이나 사용자 외래키를 만들지 않습니다.

## 적용 순서

1. PostgreSQL 데이터베이스와 전용 애플리케이션 사용자를 만듭니다.
2. backend/migrations/001_postgresql_3d_schema.up.sql을 적용합니다.
3. DATABASE_URL 또는 DB_HOST 계열 환경변수를 설정합니다.
4. /health의 connections.database.ok 값이 true인지 확인합니다.

~~~bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 \
  -f backend/migrations/001_postgresql_3d_schema.up.sql
~~~

## 핵심 테이블

table: agent_settings
purpose: 환경변수보다 우선하는 3D 및 이미지 생성 설정

columns:
- setting_key VARCHAR(191) NOT NULL PRIMARY KEY
- setting_value TEXT NOT NULL DEFAULT ''
- description TEXT NULL
- updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (setting_key)

constraints:
- 설정 키는 유일해야 합니다.

migration:
- forward: 새 설정 저장소를 생성합니다.
- rollback: 테이블과 설정값을 삭제합니다.
- risk: 롤백 전에 API 키를 포함한 설정값을 별도로 백업해야 합니다.

table: world_generation_job
purpose: Meshy 작업 상태와 생성 계획 저장

columns:
- id VARCHAR(64) NOT NULL PRIMARY KEY
- user_id BIGINT NOT NULL
- sig_id VARCHAR(191) NULL
- session_id VARCHAR(191) NULL
- kind VARCHAR(64) NOT NULL DEFAULT 'house'
- source_image_asset_id BIGINT NULL
- prompt TEXT NOT NULL DEFAULT ''
- status VARCHAR(32) NOT NULL DEFAULT 'planned'
- provider_configured BOOLEAN NOT NULL DEFAULT FALSE
- provider_payload_json JSONB NOT NULL DEFAULT '{}'
- plan_json JSONB NOT NULL DEFAULT '{}'
- error_message TEXT NULL
- created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (id)
- INDEX idx_world_generation_job_user_updated (user_id, updated_at DESC)
- INDEX idx_world_generation_job_sig_updated (sig_id, updated_at DESC)

constraints:
- source_image_asset_id는 agent_media_asset 삭제 시 NULL로 변경됩니다.

migration:
- forward: 작업 상태와 공급자 응답을 JSONB로 저장합니다.
- rollback: 작업 데이터가 삭제됩니다.
- risk: 실행 중인 작업을 중단한 뒤 롤백해야 합니다.

table: world_asset
purpose: 생성된 3D 모델 URL과 메타데이터 저장

columns:
- id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- user_id BIGINT NOT NULL
- sig_id VARCHAR(191) NULL
- job_id VARCHAR(64) NULL
- kind VARCHAR(64) NOT NULL
- source_image_asset_id BIGINT NULL
- label VARCHAR(255) NOT NULL
- model_url TEXT NOT NULL
- thumbnail_url TEXT NOT NULL DEFAULT ''
- metadata_json JSONB NOT NULL DEFAULT '{}'
- status VARCHAR(32) NOT NULL DEFAULT 'ready'
- created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (id)
- INDEX idx_world_asset_user_id (user_id, id DESC)
- INDEX idx_world_asset_sig_kind_id (sig_id, kind, id DESC)

constraints:
- job_id는 world_generation_job 삭제 시 NULL로 변경됩니다.
- source_image_asset_id는 agent_media_asset 삭제 시 NULL로 변경됩니다.

migration:
- forward: GLB 자산과 리깅·애니메이션 메타데이터를 저장합니다.
- rollback: 자산 레코드만 삭제되며 S3 객체는 별도로 정리해야 합니다.
- risk: DB 롤백은 S3 파일을 복구하거나 삭제하지 않습니다.

table: world_placement
purpose: SIG별 최신 월드 배치 계획 저장

columns:
- id VARCHAR(191) NOT NULL PRIMARY KEY
- user_id BIGINT NOT NULL
- sig_id VARCHAR(191) NULL
- job_id VARCHAR(64) NULL
- plan_json JSONB NOT NULL DEFAULT '{}'
- created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (id)
- INDEX idx_world_placement_sig_updated (sig_id, updated_at DESC, created_at DESC)

constraints:
- 같은 id 저장은 PostgreSQL upsert로 plan_json을 갱신합니다.

migration:
- forward: 월드 배치 저장소를 생성합니다.
- rollback: 저장된 배치가 삭제됩니다.
- risk: 클라이언트가 보유한 배치와 불일치할 수 있습니다.

table: world_meshy_animation_catalog
purpose: Meshy 애니메이션 원본 카탈로그 저장

columns:
- action_id INTEGER NOT NULL PRIMARY KEY
- action_key VARCHAR(160) NOT NULL
- name VARCHAR(255) NOT NULL
- category VARCHAR(120) NOT NULL
- sub_category VARCHAR(160) NOT NULL
- rig_type VARCHAR(80) NOT NULL DEFAULT ''
- tag VARCHAR(120) NOT NULL DEFAULT ''
- preview_url TEXT NULL
- is_default BOOLEAN NOT NULL DEFAULT FALSE
- is_free BOOLEAN NOT NULL DEFAULT FALSE
- created_at_ms BIGINT NOT NULL DEFAULT 0
- source_json JSONB NULL
- synced_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (action_id)
- INDEX idx_world_meshy_animation_catalog_order

constraints:
- action_id는 Meshy 카탈로그 식별자입니다.

migration:
- forward: /api/world/animations/catalog?sync=true 요청이 데이터를 upsert합니다.
- rollback: 동기화된 카탈로그와 슬롯 매핑이 삭제됩니다.
- risk: 다음 동기화 전까지 DB 카탈로그를 사용할 수 없습니다.

table: world_meshy_animation_slot_option
purpose: 캐릭터 애니메이션 슬롯별 동작 순서와 기본값 저장

columns:
- slot_key VARCHAR(32) NOT NULL
- action_id INTEGER NOT NULL
- sort_order INTEGER NOT NULL DEFAULT 0
- is_default BOOLEAN NOT NULL DEFAULT FALSE
- synced_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP

indexes:
- PRIMARY KEY (slot_key, action_id)
- INDEX idx_world_meshy_animation_slot_order (slot_key, sort_order)

constraints:
- action_id는 카탈로그 삭제 시 함께 삭제됩니다.

migration:
- forward: 카탈로그 동기화 시 슬롯 데이터를 교체합니다.
- rollback: 슬롯 데이터가 삭제됩니다.
- risk: 동기화 중 실패하면 다음 동기화로 다시 구성해야 합니다.

## 보조 테이블

- agent_media_asset: 기존 이미지 자산 ID를 3D 참조 이미지 URL로 해석합니다.
- agent_usage: 참조 이미지 생성의 토큰 사용량을 기록합니다.
- media_model_catalog: 사용할 수 있는 이미지 모델과 기본 모델을 정의합니다.
- media_model_option: 이미지 모델별 선택 옵션을 정의합니다.
- media_model_capability: 이미지 모델별 기능 지원 여부를 정의합니다.

## 롤백

backend/migrations/001_postgresql_3d_schema.down.sql은 위 테이블을 의존성 역순으로 삭제합니다.
운영 데이터와 S3 객체 목록을 백업한 경우에만 직접 실행해야 합니다.
